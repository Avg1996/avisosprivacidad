2. Acerca de QRMaster

QRMaster es una aplicación para dispositivos Android que permite leer, escanear y generar códigos QR de manera sencilla.

Entre sus funcionalidades se encuentran:

  • Escaneo de códigos QR mediante la cámara del dispositivo.
  • Lectura e interpretación del contenido de códigos QR.
  • Generación de códigos QR a partir de texto y otros contenidos compatibles.
  • Visualización de los resultados de los códigos escaneados.

3. Información que puede tratar la aplicación

Dependiendo de las funciones utilizadas y de la versión instalada, QRMaster puede procesar los siguientes tipos de información:

  • Contenido de códigos QR: texto, direcciones web, enlaces, datos de contacto u otra información codificada.
  • Imágenes: fotografías o imágenes seleccionadas por el usuario para analizar códigos QR.
  • Datos generados: información que el usuario introduce para crear sus propios códigos QR.
  • Información técnica: datos del dispositivo o registros técnicos, únicamente si las herramientas integradas en la aplicación los recopilan.
QRMaster no necesita que el usuario introduzca información personal para realizar las funciones básicas de lectura y generación de QR.

4. Permisos del dispositivo

Cámara

La aplicación puede solicitar acceso a la cámara para detectar, enfocar y escanear códigos QR. Este permiso se utiliza para proporcionar la función de lectura.

Fotos y archivos

Si la aplicación permite importar imágenes, podrá solicitar acceso al selector de fotografías o archivos para analizar códigos QR contenidos en ellos.

Los permisos se utilizan únicamente para las funciones correspondientes y pueden administrarse desde la configuración del dispositivo Android.

5. Uso y almacenamiento de la información

El contenido introducido, escaneado o generado puede procesarse dentro del dispositivo para ejecutar las funciones de QRMaster.

La información que se guarde en el historial o en otras funciones de la aplicación dependerá de las características habilitadas en la versión instalada.

No se debe interpretar este aviso como una garantía de que todos los datos permanecen exclusivamente en el dispositivo: cualquier servicio externo, sincronización o herramienta de terceros que se incorpore deberá identificarse y explicarse aquí.

6. Compartición de información

AVG Web no comercializa los datos personales de los usuarios.

Cuando el usuario decide compartir un código QR, abrir un enlace o utilizar una aplicación externa, la información correspondiente puede ser enviada al servicio elegido por el propio usuario.

Los servicios externos se rigen por sus propios avisos de privacidad y condiciones de uso.

7. Seguridad

Se adoptan medidas razonables para proteger la información relacionada con la aplicación. Sin embargo, ningún sistema informático puede garantizar una seguridad absoluta.

Se recomienda evitar escanear códigos QR de origen desconocido, especialmente cuando contienen enlaces o solicitan información confidencial.

8. Enlaces y códigos QR externos

QRMaster permite interpretar códigos QR que pueden contener enlaces a sitios web, aplicaciones o servicios externos.

La aplicación no controla las prácticas de privacidad, el contenido ni la seguridad de dichos sitios. El usuario debe verificar el destino antes de abrir cualquier enlace.

9. Privacidad de menores

QRMaster no está diseñada específicamente para recopilar información personal de menores de edad. Si se detecta que se ha recopilado información personal de un menor sin las autorizaciones correspondientes, se atenderá la situación conforme a la legislación aplicable.
